# AquaScholar Portfolio

Premium multi-page academic portfolio for Dr. Sachchidanand Singh, created from the verified content of AquaScholar.

## Open locally

Open `index.html` in a modern browser. No installation, package manager, build command, or web server is required.

## Pages

- Home
- About
- Research
- Publications
- Projects
- Field Visits
- Lectures & Tutorials
- Web Apps
- HIM-CHITRA
- WASAP
- Awards & Certificates
- Skills
- Memberships
- CV
- Contact

## Structure

- `data/content.js` contains the structured profile, projects, publications, lectures, apps, awards, training, skills and membership content.
- `assets/app.js` contains reusable rendering components and interactions.
- `assets/styles.css` contains the responsive design system, animation and accessibility styles.
- `assets/images/` contains the local profile and Himalayan/geospatial visual assets.
- `previews/` contains desktop and mobile verification captures.

## Notes

- The project retains the existing static HTML/CSS/JavaScript stack.
- The contact form prepares an email in the visitor's email application and does not store or transmit form data through a backend.
- The CV button links to the verified AquaScholar CV page because a stable direct PDF URL was not exposed by the source page.
- External Google Earth Engine applications remain subject to their access and platform availability.

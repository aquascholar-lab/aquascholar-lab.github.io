# AquaScholar redesign

A responsive static redesign for [aquascholar.in](https://www.aquascholar.in/).

## Preview

Open `index.html` in a modern browser. The site uses plain HTML, CSS, and
JavaScript, so no build step is required.

## Files

- `index.html` - page structure and verified AquaScholar content
- `styles.css` - responsive visual system and motion
- `script.js` - navigation, reveal effects, counters, and scroll-driven 3D motion
- `assets/himalayan-watershed.png` - original generated hero artwork
- `assets/dr-sachchidanand-singh.png` - portrait from the published AquaScholar profile
- `assets/satellite-observation.png` - original generated 3D satellite artwork
- `assets/himalayan-terrain-3d.png` - original generated 3D watershed artwork
